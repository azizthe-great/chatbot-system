# Chatbot System

A small, dependency-free chatbot that runs locally with Node.js. It uses rule-based responses and can be extended with a real AI API later.

## Run

```bash
npm start
```

Open http://localhost:3000 in a browser.

## Test

```bash
npm test
```

## Project structure

- `server.js` — HTTP server and static file serving
- `chatbot.js` — Chatbot response logic
- `public/` — Web interface
- `test/` — Automated tests
